=================
Installing on Mac
=================

#. Download the Mac installer (**MetadataWizard-v2.2.1.pkg**) from the `GitHub releases page <https://github.com/DOI-USGS/fort-pymdwizard/releases>`_.

#. Double click on the downloaded installer file to begin the installation.

**Installation may require elevated (administrative) privileges.** After installation the MetadataWizard can be launched from the duck icon (|duck|) in the user’s applications.

**"Data Access Blocked" notification:** If Google Chrome is installed, macOS may show this message when you open the Metadata Wizard. It is expected and does not affect the Metadata Wizard (you can leave the access blocked).
