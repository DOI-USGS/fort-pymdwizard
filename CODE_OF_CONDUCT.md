## Code of Conduct

All contributions to - and interactions surrounding - this project will abide by
the rules of [USGS Scientific Integrity][1] and the [USGS Fundamental Science Practices][2].

[1]: https://www.usgs.gov/office-of-science-quality-and-integrity/scientific-integrity 
[2]: https://www.usgs.gov/office-of-science-quality-and-integrity/fundamental-science-practices
