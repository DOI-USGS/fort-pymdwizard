Changes
=======

2.2.0 (07/02/2026)
-----

Updates to associated Python environment (built into the Metadata Wizard installer)
--------------
1. Updated Python environment to 3.13.11 to address identified vulnerabilities. Edits to codebase for compatibility with updated Python libraries.
2. Replaced requirements.txt with environment.yml for package management.
3. Updated DOI certificate support to improve user connection with APIs (e.g., Crossref API for 'Import from DOI' feature)

Code cleanup
-------------
4. Added inline comments and doc strings to most scripts.
5. Updated library imports as they included legacy support for Python 2.7.
6. Fixed scripts that were importing libraries in functions.
7. Removed hardcoding of software version.
8. Updated older methods of string and variable formatting (.format() in 2.7) to F-strings, which is used in Python 3.
9. Removed sip import requirements from mdattr.py and MainWindow.py.
10. Fixed QPainter double-initialization error in MainWindow.py. Fixed Qt runtime errors in wiz_widget.py.
11. Updated user documentation and scripts to fix broken/outdated URLs and references.

Updates and bug fixes in Metadata Wizard GUI
--------------
12. Fixed multiple digform (digital form) elements being deleted on save.
13. Fixed networkr URLs from all digforms loading into the first digform UI element.
14. Added formname field to distribution UI and updated GUI label (changed "Format Name:" to "Data Format:").
15. Updated thesaurus search to improve display of keyword details.
16. Fixed taxonomy merge bug - handle missing parent taxa in merge_taxons().
17. Moved 'Import from DOI' button to more visible location in the 'Citation' sections. Fixed button size issue for high-resolution displays.
18. Fixed Dataset Title field height to display text correctly.
19. Added gate for in-app updates only if Python ≥ 3.13 (prevents older installs from breaking).
20. Improved ITIS window positioning to center on main application window and support multi-monitor setups. Updated ITIS web service URL to use HTTPS.
21. Fixed bounding box map not updating when importing spatial details from a different dataset via 'Browse to dataset' button.
22. Enabled parsing of .dbf file format in the 'Entity and Attributes' tab. DBF files are the tabular components of shapefiles.
